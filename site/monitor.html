수집 기준

  • 매일 미국 동부 오전(13:07 UTC 예약, GitHub 사정으로 늦어질 수 있음) GitHub 서버의 새 브라우저로 공개 페이지를 엽니다. 언어 en-US, 시간대 New York, 화면 1366×1500.
  • 실행마다 접속 국가 코드만 기록합니다(IP 주소는 저장하지 않음). 미국으로 확인되지 않으면 상단에 "미검증"으로 표시합니다.
  • 로그인하지 않습니다. 회원 전용 혜택 플랫폼은 공개 입구까지만 확인합니다. 봇 확인 화면·차단은 우회하지 않습니다.
  • 날짜는 미국 동부 기준이며, 같은 날 다시 수집하면 그날 값을 최신 화면으로 바꿉니다.
  • 요율은 지면에 표시된 대표 문구입니다. "Up to"는 최대치이고, 카테고리·제외 조건에 따라 실제 적용은 다릅니다.
  • 브랜드 노출은 딜·리뷰 지면 본문의 이름 언급 횟수이며 광고 집행·노출량·구매 결과를 뜻하지 않습니다.
  • 요율은 포털마다 정해진 자리(상점 이름 옆 대표 요율)에서만 읽습니다. 같은 화면의 카테고리 요율보다 높게 읽히거나, 직전 게시 값에서 크게 바뀌었는데 두 번째 근거(“was N%” 같은 상향 표시, 카테고리 요율 일치, 다음 날 같은 값)가 없으면 ‘요율 확인 필요’로 두고 게시하지 않습니다.
  • 변화 감지는 읽어 낸 값(요율·카테고리·제외 문구·오퍼)을 비교합니다. 본문 전체 지문은 개인화·위젯 때문에 자주 바뀌므로 참고로만 둡니다.
  • 공개 저장소이므로 내부 성과 수치는 넣지 않으며, 커밋 전에 자동 점검으로 막습니다.
